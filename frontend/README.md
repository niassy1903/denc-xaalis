# 💻 Denc Xaalis - Frontend React & Tailwind CSS

Application Web SPA pour les membres et présidents de tontines au Sénégal.

## 🚀 Démarrage

```bash
# 1. Installation
npm install

# 2. Lancement sur le port 5173
npm run dev

# 3. Build pour la production
npm run build
```

L'application tourne sur **`http://localhost:5173`** et communique avec le backend Express configuré sur `http://localhost:5000`.
